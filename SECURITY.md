# Security

Report vulnerabilities using GitHub private vulnerability reporting for this repository. Do not post credentials, raw recordings, or actionable access details in public issues.

The main security boundaries are device pairing, server credentials, camera-produced scene data, user confirmation, and the robot motion authority. Images, transcripts and model outputs are untrusted. A model response cannot grant motion permission.

This development preview is not a certified robot safety system. Physical installations require an independent emergency stop and qualification of the actual robot, workspace and controller.
