# Запуск на русском

Rokid Physical AI — голос и зрение физического AI-агента через очки Rokid. Первый сценарий: указать предмет, назвать зону, подтвердить перенос и услышать результат.

## Быстрый старт

Требуется **Python 3.14+**. Установите зависимости и запустите диагностический сервер:

```sh
uv sync --locked --all-groups
uv run rokid-agent doctor
uv run rokid-agent serve --host <АДРЕС_ПК_В_ЛОКАЛЬНОЙ_СЕТИ> --diagnostic
```

Соберите Android-приложение, установите его через уже сопряжённый ADB и выполните `rokid-agent pair`. Полные команды находятся в [инструкции установки](quickstart.md). Прошивка очков остаётся штатной.

Сопряжение не включает запись. Рабочая сессия начинается при открытии приложения пользователем. Камера и микрофон передают данные на компьютер; диагностический режим не отправляет их модели и не управляет роботом.

Для локальной проверки команды «выключись» добавьте к диагностическому запуску `--vosk-model <КАТАЛОГ_ЛОКАЛЬНОЙ_МОДЕЛИ>`. Без этого параметра диагностический режим проверяет только медиатранспорт и тестовый звук. Модель и её контрольная сумма указаны в [инструкции установки](quickstart.md).

Интерфейс рассчитан на прозрачный монохромный экран: чёрный фон и две короткие строки. Если очки подключены к iPhone как наушники, приложение запрашивает временный аудиофокус и освобождает его при завершении. Сопряжение Bluetooth и системную громкость оно не меняет. При потере аудиофокуса сессия прекращается, движение автоматически не возобновляется.

Для диалога задайте `OPENAI_API_KEY` только в окружении сервера и подключите локальную русскую модель распознавания команд. Для робота дополнительно нужны Linux-контроллер, камера глубины и калибровка рабочего места.

## Голосовое управление

- «Переложи этот предмет сюда» — запрос действия с указанием на предмет и назначение.
- «Подтверждаю» — разрешение после озвученного описания задачи.
- «Стоп» / «Отмена» — остановка и отмена.
- «Выключись» — завершение рабочей сессии.

Универсальная совместимость с любыми руками не заявляется: каждая модель требует адаптера и проверки. Фактическое состояние реализации и испытаний — в [матрице проверки](verification.md).
